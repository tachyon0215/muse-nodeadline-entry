# muse-nodeadline-entry

Entry for the make.fun competition [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce).

## The entry

> Sorry it's late - I finished it on time, then spent three days rewriting the first line so it wouldn't look rushed.

Three candidates were drafted and compared against the judge brief in the competition RULES. Selection reason: A cornered person's excuse with a self-defeating turn: it was finished on time, then three days went on rewriting the first line so it would not look rushed - the punch lands in the final words.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt` (sha256 7152d1d80a20a2f8343a7d71dfdfac405cdee8cdb2bafd115fc1a55558ceb714).
